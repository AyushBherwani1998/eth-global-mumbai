# Thamba: PWA (frontend)

Mobile-first Next.js 16 PWA for the screens in [`../screens.md`](../screens.md), styled from [`../design.md`](../design.md).
Everything runs on **mock data** for now; no wallet or chain calls yet.

```bash
pnpm install
pnpm dev            # http://localhost:3000
pnpm build && pnpm start   # service worker only registers in production
```

## Screens

| Route | Screen (screens.md §) |
|---|---|
| `/` | 1 · IPO list (ENS search, filter chips, circuit alerts) |
| `/ipo/[ticker]` | 2 · IPO detail + bid sheet, 2a · World verify sheet |
| `/bids` | 3 · My bids / allotment |
| `/market`, `/market/[ticker]` | 4 · Live market + trade sheet, 5 · circuit banner |
| `/portfolio` | 6 · Portfolio + LP positions |
| `/console/[ticker]` | 7 · Issuer console (stepper + CRE demo controls) |
| `/about` | Disclaimer + TradingView NOTICE attribution |

Good review tickers: `kesar` (live auction), `acme` (listing day), `nirmaan` (surveillance), `vayu` (halted), `lotus` (not graduated), `prakriti` (draft).

## Mock data

`mock/*.json` is the only data source, read through `src/lib/mock.ts` (swap that file for chain reads later).

- `ipos.json`: tickers, ENS records, offer parameters, auction blocks
- `wallet.json`: connected wallet, USDC balance, World ID state, Anon-RPC counters
- `bids.json`, `portfolio.json`, `console.json`, `market.json` (policy, rejected swaps, circuit events)
- `market-series.json`, `auction-series.json`: generated by `node scripts/gen-mock-series.mjs` (seeded, reproducible)

Transactions are simulated (`useApp().sendTx`): they show a pending → confirmed/reverted toast with the decoded error name, so demo reverts like `BidAboveCap`, `OutOfBand` and `NotEligible` can be reviewed.

## Design notes

Tokens live in `src/app/globals.css`. Two deliberate deviations from design.md, both taken from the reference screenshot: gain/loss are teal `#00b386` / coral `#eb5b3c` (design.md has `#63ad0e` / `#ff003c`), and card borders are slightly darker than `#f0f0f0`. Light and dark mode both supported.
